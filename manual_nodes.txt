# 手动节点池：补 VPN Gate 里稀缺的国家（尤其美国）
# 格式：每行 `host:port 国家代码`，# 之后是注释，空行自动忽略
# 支持写法：域名 / IPv4 / [IPv6]
#
# 示例（把下面几行替换成你自己确认可用的节点，或直接删掉不要的）：
# vpn225320874.opengw.net:995 US
# 47.203.202.164:995 US        # 美国，DESKTOP-xxx 的住宅出口
# 66.114.142.213:443 US
#
# 注意：
#   1. 这里写进来的节点会直接进入检测队列，不经过 VPN Gate 的 CSV/TCP 过滤
#   2. 端口必须是该节点实际监听的 TCP 端口（SSTP 走的也是这个端口）
#   3. 检测仍会调用你的 Worker，可用性以检测结果为准；失败不会进 nodes.txt
#   4. 建议只放 US/CA 这类 VPN Gate 里的短板国家，别把整个池子搬进来
#
